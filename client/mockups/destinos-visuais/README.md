# Alimentação e descarte

Proposta aprovada para o cartão de consumo e seu detalhe, usando os valores da captura fornecida: alimentação de 69 L (23 L limpo, 43 L sujo, 3 L colostro), descarte físico separado de 2 L e retiradas internas em aberto. Os valores estáticos são somente referência visual; a implementação operacional usa a consulta real do sítio/período. Alternância visual/tabela e ajuda por item preservadas. Não grava nem importa dados.
