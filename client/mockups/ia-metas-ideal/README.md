# IA Terrano e Metas — proposta

Proposta visual para as páginas da IA Terrano (`index.html`, abas Conversa e Radar) e de Metas (`metas.html`), feita a partir da revisão de UI do PR #357. Dados fictícios, no formato da seed de desenvolvimento; o mockup não consulta a API.

Cada página termina com uma seção “O que muda em relação ao PR #357”. As mudanças que dependem de comportamento novo, e não só de layout, são a apuração automática diária das metas, o cartão de confirmação de registro na conversa e as prioridades do Radar com prazo e ação.
