Planos e artefatos do modelo anterior não fazem parte desta base. A aparência atual da aplicação não é uma direção visual aprovada para novas entregas. Para novas features, crie documentação focada na mudança e diferencie requisitos propostos, comportamento implementado e validação realizada. A existência de código ou de um roteiro não comprova homologação de um ambiente.
