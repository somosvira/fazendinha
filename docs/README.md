Planos e artefatos do modelo anterior não fazem parte desta base. A direção Cooperativa contemporânea está documentada para o escopo desta entrega; novas direções visuais precisam de definição própria. Para novas features, crie documentação focada na mudança e diferencie requisitos propostos, comportamento implementado e validação realizada. A existência de código ou de um roteiro não comprova homologação de um ambiente.
