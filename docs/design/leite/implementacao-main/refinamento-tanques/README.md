# Aferição geral no padrão da V5

A aferição por tanque reaproveita o tema Cooperativa, os cartões das sessões e o resumo lateral da interface individual. O modo de aferição usa seleção compacta; salvar a aferição e confirmar a entrada no estoque continuam separados. Configurações de produção e tanques usam `PainelCadastro`, botões e seletores compartilhados, com corpo rolável e rodapé acessível. A qualidade individual mantém os resultados e as unidades do laudo.

## Evidências visuais

Capturas dos componentes React reais em uma montagem local com respostas ilustrativas, sem API operacional ou banco. O tema completo foi carregado, incluindo os estilos de formulário e tipografia usados pelo aplicativo. Não comprovam autenticação, persistência, migrations, integração com dados reais ou homologação da fazenda.
