# Helpers históricos da seed V5

O executor demonstrativo V5 foi retirado. O cenário atual usa somente a [seed única](../seed/README.md), com o contrato de execução em [desenvolvimento](../../../docs/desenvolvimento.md).

Os módulos remanescentes desta pasta são helpers cobertos por testes de retomada e segurança. Não são uma entrada de carga e não dependem de reexecutar os cenários antigos. Manifestos privados anteriores devem ser preservados; não são convertidos por estes helpers.
